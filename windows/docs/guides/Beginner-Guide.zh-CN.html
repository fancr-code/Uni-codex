Codex Windows 离线安装器：新手指南

公开源码状态：当前不公开镜像官方 Codex 桌面 MSIX。 请先从 Microsoft Store 官方页面 安装 Codex，再使用 Uni-codex。最低要求为 Windows 10 1809（Build 17763）x64。

1. 下载、校验、运行

  1. 不要使用旧 PowerShell 一键脚本、ZIP 正式包或第三方镜像。
  2. 用 Get-FileHash .\Codex-One-Click-Windows-x64-Offline-Setup.exe -Algorithm SHA256 计算哈希。
  3. 与 SHA256SUMS.txt 逐字核对；不一致就删除文件并停止。
  4. 双击 EXE，按界面选择服务商、模型和认证方式。
当前 EXE 为 unsigned，SmartScreen 可能警告。SHA-256 一致只说明文件与该 Release 一致， 不能替代发布者签名；来源或哈希不可确认时不要运行。 只有文件名和 SHA-256 都匹配时，才可在 SmartScreen 中选择“更多信息”→“仍要运行”； 任一项不匹配就点击取消。

无需 OpenAI 账号即可使用。安装器内的“申请 API Key”打开官方页面：

安装器优先从所选服务商的官方模型接口刷新上游模型，失败时使用离线快照； Kimi 开放平台快照包含 Kimi K3。实际模型调用和刷新需要网络。

3. 可选 OpenAI 账号授权

推荐“OpenAI 账号 + 所选国产 API”。在安装器内点击“获取 OpenAI 授权”， 完成浏览器或设备码流程。授权不等于 GPT API Key，不提供 GPT API 额度， 也不会获得账号未拥有的模型、插件或组织权限；模型仍由所选服务商调用和计费。

4. 安装器会做什么

  • 复用健康 Codex，不重复安装、不降级。
  • 安装带 cross-provider-content-v1 的 Codex++。
  • 预配置 3 个市场、9 个插件；其中 5 个插件离线实装，4 个官方生产力插件在联网且权限满足时由 Codex 运行时供应。
  • 启用 Context Used Meter 与 Codex Token Usage。
  • 对 API Key、OAuth Token、设备码、日志与安装报告脱敏。

Context Used Meter 显示在会话页左上角的可拖动浮窗； Codex Token Usage 显示在最新助手消息的操作区。要关闭任一项， 请在 Codex++ 的 Scripts/脚本市场中关闭对应名称的开关。

取消或失败时安装事务会自动回滚。脱敏报告位于 %LOCALAPPDATA%\Codex One Click Installer\reports， 可从安装器完成页打开。

5. Uni-Scholar 生态优势

Uni-Scholar 云端工作站负责云端检索与协作； Research Kit 本地中枢连接 Zotero、Obsidian 和本地知识库；Codex/Codex++ 执行层完成代码、文档、数据和自动化， 共同形成连续科研工作流。

Research Kit 是 macOS 生态链接与可选配套，不随 Windows 安装包预装。
